RealFinder Guide

A file browser for macOS that keeps Finder's habits and fixes its annoyances.

Getting around

  • Windows and tabs. ⌘N opens a new window, ⌘T a new tab. Drag a tab out to make it a window. Your windows and tabs come back when you relaunch.
  • Sidebar. Favorites and Locations (your disks, with eject buttons). Click to go there. Drag folders onto the sidebar to add them; drag a favorite out, or right-click it, to remove it.
  • Back and Forward. ⌘[ and ⌘]. Going back selects the item you had selected.
  • Enclosing folder. ⌘↑ goes up one level and selects the folder you came from. ⌘↓ opens the selection.
  • Path bar. Click any folder in the path bar at the bottom to go there.
  • Type a path. ⇧⌘G, or double-click the path bar, turns it into a field. Type a path (~ works), press Tab to complete folder names, Return to go, Esc to cancel. A file path opens its folder with the file selected.
  • Status bar. Shows the item count, how many are selected and their total size, how many items are hidden, and free space.

Views

Icons (⌘1), List (⌘2), Columns (⌘3) and Gallery (⌘4), from the View menu or the toolbar. The slider in the status bar sets the icon size.

  • Switching views never changes the order. Both views show the same sorted list, and your selection stays put.
  • List view. Click a folder's disclosure triangle (or press → / ←) to expand it in place; ⌥-click expands everything inside. Right-click the column headers to choose columns. Drag headers to reorder them, drag their edges to resize.
  • Column view. Selecting a folder shows its contents in the next column; selecting a file shows a preview with its details. → goes into the selected folder, ← back out. Searches start in the folder of the column you're in. Every column uses the same sort order.
  • Gallery view. A large preview of the selected item, a filmstrip below (←/→ to move), and its details on the right.
  • Thumbnails. Icon view shows previews of images, PDFs and other documents. Files in iCloud that aren't downloaded get a preview without being downloaded.

Sorting and grouping

Use the Sort button in the toolbar, the View menu, or (in list view) the column headers.

  • Click a column header to sort by it; click again to reverse. Dates and sizes start newest and largest first.
  • Shift-click a header to add a second sort key, e.g. sort by Kind, then by Date Modified.
  • Sorted by a hidden column? List view shows “Sorted by Date Added ↓” above the list instead of quietly switching to another column. Show Column adds it.
  • Names sort naturally, like Finder: “file 2” comes before “file 10”.
  • Empty values go last in both directions, e.g. folders when sorting by size.
  • Group By Kind, Date Modified, Date Created, Date Added or Size. Sorting applies within each group.
  • Keep Folders on Top works in every view.
  • Filter by Kind shows only certain kinds of files in the current folder, e.g. only images. Choose All Kinds to show everything again.
  • Hidden files. ⇧⌘. shows or hides them.

Which settings apply where

Finder remembers view settings per folder in a way that's hard to predict. RealFinder keeps it simple:

  • By default, your view, sort order, grouping and filters are the same in every folder. Change them anywhere and they apply everywhere.
  • To give a folder its own settings, choose View › Remember Settings for This Folder. Choose it again to forget them. These survive renaming or moving the folder.
  • Search results have their own settings (list view, with a Where column), separate from folders.

Searching

Press ⌘F or click the search field. Searches start in the current folder and its subfolders; the field says where (“Search “Projects””). From Computer, searches cover the whole Mac.

While searching, a bar below the toolbar lets you change:

  • Where: the folder you started in, or This Mac.
  • Subfolders: turn off to only filter the items directly in the folder.
  • Names or Names & Contents. Names is the default; matching contents tends to bury what you're looking for.
  • Kind chips: Folders, Documents, Images, Video, Audio, Programs, Archives, Code, PDFs, Fonts. Select several to match any of them. The chips add kind: filters to the search text, so you can always see the whole search.
  • Keep searching in new folders: when on (the default), going to another folder with the sidebar, path bar, Go menu or ⌘↑ searches there instead of ending the search.
  • Results show a Where column with each item's folder relative to where you searched. Sorting works as everywhere else.
  • Show in Enclosing Folder (⌘R or right-click) goes to a result's folder with it selected; Back returns to the results.
  • Opening a folder from the results shows its contents; Back returns to the results.
  • Ending a search: Esc, or clear the field. You're back in the folder with your previous selection.
  • Recent searches: click the magnifying glass in the search field for your last 12 searches (each remembers where it searched). Choose one to run it again. Searches are saved when you leave them, not while you type.
  • Nothing runs by itself at launch. Tabs that were showing search results reopen on the folder you searched, with the search in the field, and your most recent search is filled in when there's nothing else. Press Return to run it.
  • Finds what Spotlight misses. Folder searches use Spotlight for quick first results and also scan the folder directly, so unindexed drives, network shares and (with hidden:yes) hidden files are found too.

Big folders take a while to scan completely (for example ~20 seconds for a home folder with 200,000 folders). Results appear as they're found, and the status bar shows progress.

Search filters

Words you type match file names: case and accents don't matter, and every word must appear. Add filters anywhere in the field; separate them with spaces or commas.

If a filter can't be read (say size:>1XB), the search bar says so in orange instead of silently finding nothing.

Examples

  • size:>1MB, modified:<7d, created:2026: big files from this year, changed this week.
  • invoice kind:pdf -draft: PDFs with “invoice” in the name, but not drafts.
  • kind:images added:<1d: images added today, e.g. new downloads.
  • *.log hidden:yes size:>100MB: large log files, including in hidden folders.

Opening and previewing

  • Open with a double-click, ⌘O or ⌘↓. ⌘-double-click a folder to open it in a new tab.
  • Quick Look: Space or ⌘Y. Arrow keys move through the selection while it's open.
  • Right-click for Open With, Show Package Contents (for apps and bundles), Copy Path, and Quick Look.
  • Copy Path: ⌥⌘C copies the selected items' paths.
  • Type to select: start typing a name to jump to it.

Copying, moving and renaming

  • Copy and paste: ⌘C, then ⌘V in another folder. Pasting into the same folder makes a copy (“report copy.pdf”).
  • Cut and paste moves: ⌘X dims the items; ⌘V moves them. (⌥⌘V moves copied items, as in Finder.)
  • Drag and drop: onto a folder, empty space, or a sidebar location. Within one disk a drag moves; to another disk it copies. Hold ⌥ to copy, ⌘ to move. Drag to the Trash in the Dock to delete.
  • Rename: select an item and press Return. Type the new name, Return to keep it, Esc to cancel. You're asked before an extension changes.
  • New Folder ⇧⌘N (then name it), New Folder with Selection ⌃⌘N, Duplicate ⌘D.
  • Move to Trash ⌘⌫. Delete Immediately ⌥⌘⌫ asks first and can't be undone.
  • Undo ⌘Z and Redo ⇧⌘Z work for everything except Delete Immediately, across all windows.
  • When a name is taken you choose Keep Both (adds “2”), Replace, Skip or Stop, optionally for all remaining items. Replace moves the old item to the Trash, so you can undo it.
  • Progress: the toolbar shows a spinner while files are being copied or moved; click it to see progress, pause, resume or stop.
  • Nothing half-copied: copies are written under a hidden temporary name and only appear when complete. If an item can't be copied, the rest still are, and you get a list of what failed.

Tags

  • Tag dots show next to names in every view.
  • Tag items: right-click › Tags and choose a color tag (choose it again to remove it), or Tags… to type any tags. Tag changes can be undone.
  • Find tagged files: click a tag in the sidebar, or search with tag:Red.

Privacy and access

macOS asks before any app reads Desktop, Documents, Downloads, external drives and network volumes; allow RealFinder when asked. Some places (Mail, Messages and Safari data, other users' folders, the Trash) need Full Disk Access: System Settings › Privacy & Security › Full Disk Access, then add RealFinder.

Not yet available

RealFinder is under construction. Use Finder for these for now:

  • Get Info, comments, aliases, compressing.
  • Recents, Trash, network browsing and Connect to Server, iCloud download controls.
  • Saved searches (smart folders).
