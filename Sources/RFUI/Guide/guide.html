Foray Guide

A file browser for macOS that keeps Finder's habits and fixes its annoyances.

Getting around

  • Windows and tabs. ⌘N opens a new window, ⌘T a new tab. Drag a tab out to make it a window. Your windows and tabs come back when you relaunch.
  • Sidebar. Favorites and Locations (your disks, with eject buttons). Click to go there. Drag folders onto the sidebar to add them; drag a favorite out, or right-click it, to remove it.
  • Recents (top of the sidebar, or ⇧⌘F) lists files you've opened in the last 30 days, newest first, with when you last opened each and where it is. Folders, apps and files in your Library are left out, like Finder. It updates as you open things.
  • Cloud. iCloud Drive and services such as Dropbox, Google Drive and OneDrive appear in the sidebar's Cloud section. A small cloud next to an item means it isn't downloaded yet; opening it downloads it. Right-click for Download Now (whole folders too) or Remove Download, which frees the space but keeps the item in the cloud. Previews never download anything.
  • Servers. Go › Connect to Server… ⌘K: type an address (just “server/share” means SMB; afp://, nfs:// and https:// for WebDAV work too). macOS asks for the name and password itself and can keep them in your Keychain; Foray never sees them. Keep favorite servers with +; recent ones are listed too. File servers on your network appear in the sidebar's Network section (macOS asks once whether Foray may look on your local network); click one to connect.
  • Ejecting. Click a disk's eject button, or select it (in Computer, ⇧⌘C) and press ⌘E. If something has files open on it, Foray says which apps, so you can quit them, or you can Force Eject (unsaved changes in those apps may be lost). If the disk has other volumes too, Foray asks whether to eject them all or unmount just that one. Eject All ⌥⌘E (File menu, or right-click a disk in the sidebar) ejects every removable disk and network volume. Tabs that were showing a disk go to Computer.
  • Back and Forward. ⌘[ and ⌘]. Going back selects the item you had selected.
  • Enclosing folder. ⌘↑ goes up one level and selects the folder you came from. ⌘↓ opens the selection.
  • Path bar. Click any folder in the path bar at the bottom to go there.
  • Recent Folders (Go menu, and the Dock icon's menu) lists the last ten folders you visited.
  • Links. foray://open?path=/Users/me/Projects opens a folder (or a file's folder, with the file selected), and foray://search?q=report%20kind:pdf&in=~/Documents runs a search (leave out in for This Mac). Handy in notes, scripts and Shortcuts.
  • Type a path. ⇧⌘G, or double-click the path bar, turns it into a field. Type a path (~ works), press Tab to complete folder names, Return to go, Esc to cancel. A file path opens its folder with the file selected.
  • Status bar. Shows the item count, how many are selected and their total size, how many items are hidden, and free space.

Views

Icons (⌘1), List (⌘2), Columns (⌘3) and Gallery (⌘4), from the View menu or the toolbar. The slider in the status bar sets the icon size.

  • Switching views never changes the order. Both views show the same sorted list, and your selection stays put.
  • List view. Click a folder's disclosure triangle (or press → / ←) to expand it in place; ⌥-click expands everything inside. Right-click the column headers to choose columns. Drag headers to reorder them, drag their edges to resize.
  • Column view. Selecting a folder shows its contents in the next column; selecting a file shows a preview with its details. → goes into the selected folder, ← back out. Searches start in the folder of the column you're in. Every column uses the same sort order.
  • Gallery view. A large preview of the selected item, a filmstrip below (←/→ to move), and its details on the right.
  • Thumbnails. Icon view shows previews of images, PDFs and other documents. Files in iCloud that aren't downloaded get a preview without being downloaded.

Sorting and grouping

Use the Sort button in the toolbar, the View menu, or (in list view) the column headers.

  • Click a column header to sort by it; click again to reverse. Dates and sizes start newest and largest first.
  • Shift-click a header to add a second sort key, e.g. sort by Kind, then by Date Modified.
  • Sorted by a hidden column? List view shows “Sorted by Date Added ↓” above the list instead of quietly switching to another column. Show Column adds it.
  • Names sort naturally, like Finder: “file 2” comes before “file 10”.
  • Empty values go last in both directions, e.g. folders when sorting by size.
  • Group By Kind, Date Modified, Date Created, Date Added or Size. Sorting applies within each group.
  • Keep Folders on Top works in every view.
  • Arrange icons yourself: in icon view choose Sort By › None. Icons stay where they are, and you can drag them anywhere; Foray remembers where for each folder. New items fill the first free spots, and items dropped in from elsewhere land where you drop them. View › Clean Up lines them up on the grid. Choose any other sort to go back to automatic order.
  • Filter by Kind shows only certain kinds of files in the current folder, e.g. only images. Choose All Kinds to show everything again.
  • Hidden files. ⇧⌘. shows or hides them.

Which settings apply where

Finder remembers view settings per folder in a way that's hard to predict. Foray keeps it simple:

  • By default, your view, sort order, grouping and filters are the same in every folder. Change them anywhere and they apply everywhere.
  • To give a folder its own settings, choose View › Remember Settings for This Folder. Choose it again to forget them. These survive renaming or moving the folder.
  • Search results have their own settings (list view, with a Where column), separate from folders.

Preferences

Foray › Settings… (⌘,):

  • General: the folder new windows open on (Home unless you choose another); whether folders you open with ⌘-double-click open in tabs or windows; whether Return renames (like Finder) or opens the selection; Check for updates automatically (once a day Foray asks GitHub whether there's a newer release, and offers it; it downloads and installs only when you say so, after checking the new version is signed by Foray's developer and notarized by Apple; Foray › Check for Updates… checks any time); and Use Foray for “Show in Finder” in other apps, which makes other apps' “Show in Finder” (and “Reveal in Finder”) open Foray with the file selected. That last one is a system-wide setting; turn it off to go back to Finder.
  • Views: view settings the same everywhere, or remembered for each folder (see above).
  • Search: where searches start (the current folder, This Mac, or whatever you used last), whether they match names or names and contents, and whether a search follows you to other folders.
  • Privacy: whether Foray has Full Disk Access, with a button to the right page of System Settings.

View › Customize Toolbar… (or right-click the toolbar) adds buttons for Get Info, the Inspector, Share, Move to Trash, New Folder, Quick Look, Tags, Eject, Copy Path and Connect to Server, and lets you rearrange or remove the rest.

View options for the front window (icon size, columns, grouping and so on) are in View › Show View Options (⌘J). In list view, Calculate all sizes totals folders in the background so they show a size and sort by it.

Searching

Press ⌘F or click the search field. Searches start in the current folder and its subfolders; the field says where (“Search “Projects””). From Computer, searches cover the whole Mac.

While searching, a bar below the toolbar lets you change:

  • Where: the folder you started in, or This Mac.
  • Subfolders: turn off to only filter the items directly in the folder.
  • Names or Names & Contents. Names is the default; matching contents tends to bury what you're looking for.
  • Kind chips: Folders, Documents, Images, Video, Audio, Programs, Archives, Code, PDFs, Fonts. Select several to match any of them. The chips add kind: filters to the search text, so you can always see the whole search.
  • Keep searching in new folders: when on (the default), going to another folder with the sidebar, path bar, Go menu or ⌘↑ searches there instead of ending the search.
  • Results show a Where column with each item's folder relative to where you searched. Sorting works as everywhere else.
  • Show in Enclosing Folder (⌘R or right-click) goes to a result's folder with it selected; Back returns to the results.
  • Opening a folder from the results shows its contents; Back returns to the results.
  • Ending a search: Esc, or clear the field. You're back in the folder with your previous selection.
  • Recent searches: click the magnifying glass in the search field for your last 12 searches (each remembers where it searched). Choose one to run it again. Searches are saved when you leave them, not while you type.
  • Nothing runs by itself at launch. Tabs that were showing search results reopen on the folder you searched, with the search in the field, and your most recent search is filled in when there's nothing else. Press Return to run it.
  • Filters… in the search bar shows the search's filters in plain words (“Size is larger than 5 MB”, “Modified within the last 7 days”), lets you remove any of them, and builds new ones from menus: kind, name, extension, size, dates, last opened, tag, contents, hidden files. It edits the text in the search field, so you can mix clicking and typing.
  • Smart folders. Save… in the search bar (or File › Save Search… ⌘S) keeps a search as a smart folder, in your Saved Searches folder and, if you like, in the sidebar. It finds new matches each time you open it. Smart folders made in Finder open here too; they run Finder's own query, so only where they look can be changed. Finder can open the ones Foray saves. Searches using regular expressions can't be saved, since Spotlight can't run them.
  • Finds what Spotlight misses. Folder searches use Spotlight for quick first results and also scan the folder directly, so unindexed drives, network shares and (with hidden:yes) hidden files are found too.

Big folders take a while to scan completely (for example ~20 seconds for a home folder with 200,000 folders). Results appear as they're found, and the status bar shows progress.

Search filters

Words you type match file names: case and accents don't matter, and every word must appear. Add filters anywhere in the field; separate them with spaces or commas.

FilterExamplesFinds
kind:kind:images kind:pdf,videoFiles of these kinds
ext:ext:heic ext:jpg,pngFiles with these extensions
size:size:>100MB size:<10KB size:1MB..5MBFiles by size (KB, MB, GB)
modified:modified:<7d modified:>1y modified:todayChanged within (<) or before (>) h, d, w, m, y ago
created: added:created:2026 added:2026-10 added:yesterdayA year, month or day, or relative as above
opened:opened:<30dLast opened (Spotlight-indexed files only)
tag:tag:red tag:"Tax 2025"Files with a Finder tag
content:content:"invoice 2291"Files containing these words (Spotlight)
hidden:yesInclude hidden files and folders

If a filter can't be read (say size:>1XB), the search bar says so in orange instead of silently finding nothing.

Examples

  • size:>1MB, modified:<7d, created:2026: big files from this year, changed this week.
  • invoice kind:pdf -draft: PDFs with “invoice” in the name, but not drafts.
  • kind:images added:<1d: images added today, e.g. new downloads.
  • *.log hidden:yes size:>100MB: large log files, including in hidden folders.

Opening and previewing

  • Open with a double-click, ⌘O or ⌘↓. ⌘-double-click a folder to open it in a new tab.
  • Quick Look: Space or ⌘Y. Arrow keys move through the selection while it's open.
  • Right-click for Open With, Show Package Contents (for apps and bundles), Copy Path, and Quick Look.
  • Open With lists the apps that can open the item, the default first. Other… lets you pick any app, and can make it the default for that kind of file. Hold ⌥ in the menu for Always Open With, which opens the item and makes that app the default for all files of its kind.
  • Copy Path: ⌥⌘C copies the selected items' paths.
  • Get Info: ⌘I opens a window per selected item (or the current folder): kind, size (folders are totaled), dates, details such as dimensions or duration, tags, comments, the app it opens with, and permissions. You can change the name, Locked, Hide extension, the comment, and (for your own items) who can read and write it. Stationery pad (files) makes opening the file open a fresh copy, so the original stays a template. Under Sharing & Permissions, Add People… gives other users or groups Read & Write, Read only or Write only access (an access list), and for folders Apply to Enclosed Items… gives everything inside the same permissions. These changes can be undone. Right-click the icon at the top to copy it, paste an image as the item's icon, or remove a custom icon; dropping an image file on it works too. Show Inspector ⌥⌘I is one Get Info panel that follows the selection; with several items selected it totals their size and counts their kinds. The first time you save a comment, macOS asks whether Foray may control Finder: allowing it lets Finder show the comment too.
  • Type to select: start typing a name to jump to it.

Copying, moving and renaming

  • Copy and paste: ⌘C, then ⌘V in another folder. Pasting into the same folder makes a copy (“report copy.pdf”).
  • Cut and paste moves: ⌘X dims the items; ⌘V moves them. (⌥⌘V moves copied items, as in Finder.)
  • Drag and drop: onto a folder, empty space, or a sidebar location. Within one disk a drag moves; to another disk it copies. Hold ⌥ to copy, ⌘ to move. Drag to the Trash in the Dock to delete.
  • Rename: select an item and press Return (unless you've set Return to open things in Settings). Type the new name, Return to keep it, Esc to cancel. You're asked before an extension changes.
  • New Folder ⇧⌘N (then name it), New Folder with Selection ⌃⌘N, Duplicate ⌘D.
  • Move to Trash ⌘⌫, or drag items onto Trash in the sidebar. Delete Immediately ⌥⌘⌫ asks first and can't be undone.
  • The Trash (in the sidebar, under Locations) shows everything you've trashed, from every disk. Select items and press ⌘⌫ (or right-click › Put Back) to return them where they came from; if their folder is gone, it's recreated. Put Back works for things Finder trashed too. If Foray can't tell where something came from, it asks for a folder.
  • Empty Trash: the Empty… button at the top of the Trash, or Foray › Empty Trash… ⇧⌘⌫. It asks first (hold ⌥ to skip the question) and can't be undone. Seeing and emptying the Trash need Full Disk Access.
  • Rename many at once: select several items and choose Rename N Items… (File menu, right-click, or Return). Replace Text (optionally a regular expression, with $1 for groups), Add Text before or after, Format (“Beach 1”, “00001 Beach”, or the date modified) and Change Case. The preview shows every new name and flags clashes before anything changes. Extensions are left alone unless you include them. One Undo puts every name back.
  • Make Alias ⌃⌘A puts “name alias” next to the item. Aliases keep working when the original moves. Opening a folder alias opens the folder here. Show Original ⌘R goes to the original. If the original is gone, Foray offers Fix Alias… to point it somewhere new.
  • Compress (File menu or right-click) makes “name.zip”, or “Archive.zip” for several items, the same zip Finder makes. Expand unpacks a .zip next to itself: a single item lands beside it; several go into a folder named after the archive.
  • Spring-loaded folders: while dragging, pause over a folder (in the list, icons or sidebar) and it opens, so you can drop deep inside without letting go.
  • Drag in from other apps: attachments from Mail, photos from Photos and images from Safari can be dropped into any folder.
  • Services (Foray › Services) work on the selected files, like in Finder.
  • Quick Actions (right-click, File › Quick Actions, gallery view, or toolbar buttons you can add): Rotate Left ⌃⌘L and Rotate Right ⌃⌘R for images and PDFs (photos are turned without losing quality), Markup to draw, type or sign on an image or PDF with macOS's editor, and Create PDF to combine the selected images and PDFs, in order, into one PDF. Rotating and Create PDF can be undone; if Markup saves an edited copy, the original goes to the Trash.
  • Share… (right-click or File menu) sends the selection with AirDrop, Mail, Messages and so on.
  • Undo ⌘Z and Redo ⇧⌘Z work for everything except Delete Immediately, across all windows.
  • When a name is taken you choose Keep Both (adds “2”), Replace, Skip or Stop, optionally for all remaining items. Replace moves the old item to the Trash, so you can undo it.
  • Progress: the toolbar shows a spinner while files are being copied or moved; click it to see progress, pause, resume or stop.
  • Nothing half-copied: copies are written under a hidden temporary name and only appear when complete. If an item can't be copied, the rest still are, and you get a list of what failed.

Tags

  • Tag dots show next to names in every view.
  • Tag items: right-click › Tags and choose a color tag (choose it again to remove it), or Tags… to type any tags. Tag changes can be undone.
  • Find tagged files: click a tag in the sidebar, or search with tag:Red.

Privacy and access

macOS asks before any app reads Desktop, Documents, Downloads, external drives and network volumes; allow Foray when asked. Some places (Mail, Messages and Safari data, other users' folders, the Trash) need Full Disk Access: System Settings › Privacy & Security › Full Disk Access, then add Foray. Settings › Privacy shows whether it's on and opens that page for you. If a folder won't open because of permissions, the message says so.
